How to use

1. Enter the lab password (the LAB_PASSWORD you set in Render). 2. Pick an endpoint on the left. 3. Edit parameters or the JSON body. 4. Press Send. Calls go through your server, so your API key never reaches the browser.

Tip: run Hotels by city first to get hotel IDs, then Hotel details, Reviews and Full rates. After a test booking on the site, use Retrieve booking and Cancel booking.
